Retrieval-Augmented Generation (RAG) Overview

Retrieval-Augmented Generation (RAG) is a technique that combines a retrieval system with a
generative language model. Instead of relying solely on the parameters of a language model,
RAG first retrieves relevant passages from an external knowledge source (such as a document
collection) and then conditions the generation on that retrieved context.

The technique was introduced by Lewis et al. in 2020 in the paper "Retrieval-Augmented
Generation for Knowledge-Intensive NLP Tasks." The key motivation is that large language
models can produce fluent but factually incorrect text, a phenomenon known as
hallucination. By grounding generation in retrieved evidence, RAG systems can reduce
hallucination and provide source attribution for their answers.

A typical RAG pipeline has three stages: (1) chunking and indexing a document corpus into a
vector store, (2) embedding a user query and retrieving the top-k most similar chunks using
a similarity metric such as cosine similarity, and (3) passing the retrieved chunks along
with the original query to a language model to generate a final answer.

Common vector stores used for RAG include FAISS, Pinecone, Weaviate, and Chroma. FAISS
(Facebook AI Similarity Search) is a popular open-source library for efficient similarity
search that can run entirely locally without a server.
